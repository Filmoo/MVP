Privacy policy

Last updated: 29 September 2026

The short version. MVP has no accounts, no ads and no analytics. Most of what it does happens on your PC, from your League client. A few features ask MVP’s server, which asks Riot Games; crash reports are sent only if you turn them on. This website sets no cookies, and its only request to another site is GitHub’s API, for the list of versions.

Who is responsible

MVP is a free, open-source project run by [the maintainer’s name], [country] (“we”). For anything about your data, write to [contact e-mail, to be added before launch]. For questions that aren’t personal, you can also open an issue on GitHub.

The app on your PC

MVP reads your League client through the local interface the client opens on your PC. It reads:

  • your account’s Riot ID, rank and match history, your champion mastery and the champions you can pick;
  • champion select: the champions picked, hovered and banned, and the roles (never the names of players the game hides);
  • the game, once it loads: the Riot IDs, champions and summoner spells the loading screen shows;
  • your rune pages and item sets, when you import a build.

It writes into the client only when you ask it to, or when you turn an automation on: MVP’s own rune page, MVP’s own item set, summoner spells in champion select, and accepting a ready check (auto-accept, off by default). It never changes your own rune pages or item sets.

On your PC, MVP keeps its settings, a random install ID, a copy of the last remote configuration, the game data and statistics it downloaded, ranked emblem images, the logs of its last two runs and, only while crash reports are on, the reports waiting to be sent. They live in %APPDATA%\gg.mvp.companion and %LOCALAPPDATA%\gg.mvp.companion; deleting those folders removes them. The logs stay on your PC: Settings → About → Copy diagnostics copies them for a bug report, with names and IDs removed, and only you decide where to paste them.

What the app sends to MVP’s server

MVP’s server (api.mvpgg.com) holds the Riot API key, so the app never needs one. Every request carries the app’s version and its random install ID, which isn’t linked to your Riot account: we use it to limit how often one install can ask, to roll updates out gradually, and to find crash reports to delete on request.

  • Player search: the Riot ID and region you search for.
  • Loading-screen cards: the Riot IDs of the visible players of your game (yours included) and the region, once per game. Players in streamer mode are never sent.
  • Someone else’s game you open: its match ID.
  • Statistics: downloads of the published statistics (tier list, builds, matchups).
  • Remote configuration: at start and every few hours, for updates, notices and features paused for everyone.
  • Updates: a check at start and every six hours.
  • Crash reports, only if you turn them on (Settings → App, off by default): the error message and stack trace, the versions of the app, of Windows and of WebView2, and the install ID. Player names, IDs, file paths, e-mail addresses, passwords and IP addresses are removed in the app, then again on the server.

What the server keeps, and for how long

  • Answers from Riot’s API, in a cache: player profiles and loading-screen cards for 2 minutes, the account behind a Riot ID for a day, and match records (each game’s scoreboard: champions, items, statistics and the Riot IDs of its ten players) until newer ones push them out, 20,000 games at most. The cache is saved to the server’s disk when it restarts.
  • Crash reports: 30 days, then deleted. To have yours deleted sooner, send us the report ID that Settings shows under the switch.
  • Request logs: the time, the kind of request (“player search”, not the name searched), the answer’s status and how long it took. No IP address, no install ID, no request content.
  • Rate limits: the server counts requests per install ID (or per IP address when there is none) in memory only, never on disk.

Statistics

To compute its statistics, MVP’s server reads public ranked ladders (Emerald and above) and the games of those players through Riot’s API. It keeps the list of those accounts as Riot’s encrypted account IDs, without names, to know whose games it has read; and from each game, only facts without identities: champions, roles, items, runes, spells, skill order, result, length and damage figures. The published statistics are totals and averages over many games: nobody can be found in them. The list of accounts is kept as long as statistics are computed from it.

Services the app contacts directly

  • Riot Games’ Data Dragon (ddragon.leagueoflegends.com): game data, names and icons.
  • CommunityDragon (raw.communitydragon.org): the ranked emblem images.
  • GitHub (github.com): the latest release’s update manifest, and the installers.

Like any website, each of them sees your IP address when the app downloads from it. None of these requests carries anything about your account.

Riot Games

MVP isn’t made by Riot Games. It uses Riot’s API through our server, under Riot’s developer policies. MVP never asks for your Riot password and has no Riot sign-in. What Riot does with your data is in Riot’s privacy notice.

This website

mvpgg.com sets no cookies, has no analytics, ads or trackers, and loads no fonts or scripts from other sites. To show the versions, your browser asks GitHub’s API (api.github.com) for the list of releases: GitHub sees your IP address and browser, as with any visit to GitHub, and GitHub’s privacy statement applies. The answer is kept for 10 minutes in your browser’s session storage, so pages don’t ask again; it’s gone when you close the tab. Downloads come from GitHub. The site’s server keeps no visit logs.

Hosting

MVP’s server runs on a virtual server rented from OVHcloud. Traffic to mvpgg.com and api.mvpgg.com goes through Cloudflare, which delivers it and protects it from attacks, and sees IP addresses to do so. The code and the installers are hosted by GitHub. These providers may process data outside the European Union, under their own safeguards such as the EU’s standard contractual clauses.

Legal bases

  • The features you use (player search, loading-screen cards, opened games, statistics, updates, remote configuration): our legitimate interest in providing the app you installed and keeping it working and secure (GDPR, Art. 6(1)(f)).
  • Crash reports: your consent, given with the switch in Settings and withdrawn with it (Art. 6(1)(a)).
  • Statistics from public games, and caching Riot’s answers: our legitimate interest in providing statistics without asking Riot twice for the same thing; the data is minimal and kept briefly (Art. 6(1)(f)).

Your rights

You can ask for access to your data, its correction or deletion, object to its use or ask to restrict it, and complain to a data protection authority (in the Netherlands, the Autoriteit Persoonsgegevens). Write to [contact e-mail]; for crash reports, include the report ID from Settings. Most of what MVP handles isn’t linked to you by name: the install ID is random, and the caches hold what Riot’s API returns about Riot IDs. To have your Riot ID removed from our caches, tell us which one.

Changes

We update this policy when MVP changes. The date at the top says when; every earlier version is in the project’s public history on GitHub.
